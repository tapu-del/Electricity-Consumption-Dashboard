# Electricity-Consumption-Dashboard

## About the Project
This project is an interactive Excel dashboard built to analyze household electricity consumption patterns in India. The goal was to understand cost trends, appliance usage, and city-wise billing.

## Tools & Skills Used
* Microsoft Excel
* PivotTables & PivotCharts
* Interactive Dashboard Design
* Data Cleaning & Preparation

## Key Insights
* **Cost Trends:** A line chart tracking electricity bills over time.
* **City Analysis:** A bar chart showing which cities have the highest total electricity bills.
* **Appliance Impact:** KPIs tracking total units used and appliance counts.
